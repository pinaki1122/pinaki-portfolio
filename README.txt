Files:

- assets/pinaki-biswal.jpg: your supplied portrait
- assets/portfolio-overview.png: portfolio infographic (if included)

Preview:
Open index.html in a web browser.

Publish online:
1. Create a GitHub account and a new public repository named pinaki-portfolio.
2. Upload index.html and the assets folder (keep the folder structure).
3. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. GitHub will provide a public URL you can put on LinkedIn, Naukri, your resume, and other social profiles.

You can also drag the folder contents into a static hosting service such as Netlify Drop.
Review your contact details before publishing. The experience/project wording is based on your resume; adjust anything that doesn't accurately represent your hands-on work.
